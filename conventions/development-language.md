# Development language

## Rule

Use English as the official language for development.

Use English for file and directory names, code identifiers, public APIs, types, tokens, variants, comments, diagnostics, technical documentation, usage examples, test descriptions, commit messages, and pull request titles and descriptions. Preserve established names from dependencies and external references where applicable.

## Rationale

A shared language keeps naming, code, and technical documentation consistent.

## Exceptions

Day-to-day conversation can continue in Portuguese. Languages supported by consuming applications and the future website are separate decisions.

Public API JSDoc may append a Brazilian Portuguese translation after its complete English documentation when the API explicitly requires bilingual reference material. English remains first and canonical. Runtime diagnostics and implementation comments remain English-only.
