# Comece com a newui

Instale a biblioteca, escolha como carregar os estilos e use seu primeiro componente SolidJS. Este guia parte de uma aplicação Solid já criada com Vite ou SolidStart.

## Instale

Instale a newui e o SolidJS usando o gerenciador de pacotes do seu projeto:

```sh
bun add @egcs/newui solid-js
```

Com npm, pnpm ou Yarn, use o comando equivalente para adicionar `@egcs/newui` e `solid-js`.

## Escolha como usar os estilos

Você pode importar a folha de estilos completa ou selecionar áreas da biblioteca usando Tailwind CSS 4. Escolha apenas uma opção.

### Opção A: CSS compilado

Importe a folha completa uma vez no ponto de entrada da aplicação, por exemplo em `src/index.tsx` ou `src/entry-client.tsx`:

```tsx
import "@egcs/newui/styles.css";
```

Essa opção já inclui os estilos e o reset global da newui. Você não precisa instalar nem configurar Tailwind para usar os componentes.

### Opção B: Tailwind CSS 4

Use esta opção se quiser selecionar quais áreas de estilos da newui entram no build e usar utilitários Tailwind na sua aplicação. Ela requer Tailwind CSS 4.3.3 ou superior e PostCSS 8.5 ou superior.

Instale as dependências de desenvolvimento:

```sh
bun add --dev tailwindcss @tailwindcss/postcss postcss
```

Crie `postcss.config.mjs` na raiz do projeto:

```js
import newui from "@egcs/newui/postcss";
import tailwind from "@tailwindcss/postcss";

export default { plugins: [newui(), tailwind()] };
```

No CSS de entrada da aplicação, selecione as áreas que vai usar:

```css
@import "tailwindcss";
@import "@egcs/newui/tailwind/preset.css";
@import "@egcs/newui/tailwind/actions.css";
```

Importe esse CSS uma vez no ponto de entrada. Neste modo, não importe `@egcs/newui/styles.css`: a aplicação fica responsável pelo Preflight. O preset é opcional; ele conecta utilitários da aplicação, como `bg-primary` e `text-foreground`, aos tokens da newui. Os estilos internos dos componentes continuam usando o prefixo `nui:`.

> O modo Tailwind documentado usa o pipeline PostCSS. Tailwind 3, compilação apenas pela CLI e o plugin nativo do Tailwind para Vite não estão validados.

## Renderize um componente

Importe os componentes da área correspondente. Para começar com um botão:

```tsx
import { Button } from "@egcs/newui/actions";

export function SaveButton() {
  return <Button>Salvar alterações</Button>;
}
```

<div class="my-6 flex flex-wrap items-center gap-3 rounded-xl border border-border bg-surface p-6">
  <Button>Salvar alterações</Button>
  <Button variant="outline">Cancelar</Button>
</div>

O ponto de entrada principal também exporta os componentes. Para manter os imports próximos da área utilizada, você pode importar de `@egcs/newui/actions`, `@egcs/newui/forms` ou de outra área da biblioteca.
