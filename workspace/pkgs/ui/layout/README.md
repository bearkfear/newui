# Layout

[UI package](../README.md)

Organize space, alignment, flow, and sizing independently of page content.

## Components

- [Container](container/README.md): maximum width and responsive margins.
- [Section](section/README.md): consistent spacing between page sections.
- [Resizable](resizable/README.md): Ark Splitter panels with horizontal/vertical layouts, optional grips, controlled sizes, and collapsible/nested compositions.

## Composition

Use native CSS flexbox and grid for layout, gap for item spacing, and aspect-ratio for media proportions. Storybook's Layout / Media proportions demonstrates responsive media.

[Hero and Footer](../compositions/README.md) combine layout and content into larger interface compositions.
